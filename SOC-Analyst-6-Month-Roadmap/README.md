# 6-Month SOC Analyst Roadmap

A 24-week learning roadmap for building entry-level Security Operations Center (SOC) Analyst skills through theory, hands-on labs, projects, and documentation.

## About this repository

This repository tracks my learning journey after completing my BCA while studying a six-month cybersecurity course covering CNP, CAP, and ASA.

**Goal:** Prepare for entry-level roles such as SOC Analyst L1, Junior Security Analyst, or Security Operations Analyst.

> This repository documents learning and lab practice. Only mark a task complete after performing it and adding your own notes/screenshots. Perform scans and security testing only on systems you own or have explicit permission to test.

## Weekly workflow

For each week:
1. Review the syllabus in `weeks/`.
2. Write your own notes in the relevant week folder.
3. Complete the listed hands-on exercises in a safe lab.
4. Save screenshots with a short explanation (hide personal information, tokens, public IPs, and sensitive details).
5. Record findings and lessons learned.
6. Update the checklist above only after completing the work.

## Suggested evidence to add

- Wireshark captures or screenshots with explanations
- Nmap results from an authorized lab target
- Linux and Windows investigation notes

- Alert investigation reports
- Phishing and IOC analysis reports
