# Week 1: Computer Networking Fundamentals

**SOC Analyst Roadmap — Month 1, Week 1**

**Status:** Completed

## Overview

During Week 1, I studied computer networking fundamentals and practiced basic network traffic analysis using Wireshark.

## Topics Studied

* OSI Model
* TCP/IP Model
* Encapsulation and Decapsulation
* IPv4 and IPv6
* MAC Addresses and Ethernet Frames
* ARP (Address Resolution Protocol)
* ICMP (Internet Control Message Protocol)
* DNS (Domain Name System)
* DHCP (Dynamic Host Configuration Protocol)

## Hands-on Labs

### 1. Wireshark Installation

Installed Wireshark to capture and analyze network traffic.

### 2. Packet Capture

Captured network packets and explored Ethernet frames, IP addresses, and protocols.

### 3. ICMP Ping Test

Used ping to test network connectivity and understand ICMP request and reply packets.

### 4. DNS Lookup

Used DNS lookup commands to investigate how domain names resolve to IP addresses.

### 5. DNS Traffic Analysis

Examined DNS requests and responses in Wireshark to understand how DNS communication works.

## Tools Used

* Wireshark
* Ping
* nslookup

## Key Learnings

* Understood the basic purpose of each OSI layer.
* Learned how devices communicate over a network.
* Practiced identifying Ethernet frames and IP packets.
* Learned how DNS queries and ICMP packets appear in Wireshark.
* Improved my understanding of basic network troubleshooting.

## SOC Analyst Relevance

Networking knowledge helps SOC analysts understand network traffic, investigate suspicious connections, and identify potentially unusual DNS activity.
