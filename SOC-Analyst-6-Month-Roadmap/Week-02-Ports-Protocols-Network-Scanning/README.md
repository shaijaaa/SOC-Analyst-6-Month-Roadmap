# Week 2: Ports, Protocols and Network Scanning

**Roadmap:** 6-Month SOC Analyst Journey
**Status:** Completed
**Focus:** Network Communication and Port Analysis

## Overview

During Week 2, I studied network ports and protocols and practiced using network diagnostic tools to understand network connections and identify exposed services in an authorized lab environment.

## Topics Studied

* TCP vs UDP
* TCP Three-Way Handshake (SYN, SYN-ACK, ACK)
* Common ports and protocols:

  * FTP — 20/21
  * SSH — 22
  * Telnet — 23
  * SMTP — 25
  * DNS — 53
  * HTTP — 80
  * POP3 — 110
  * IMAP — 143
  * HTTPS — 443
  * RDP — 3389
* Network Address Translation (NAT)
* Virtual Private Networks (VPNs)
* Proxy servers
* Virtual LANs (VLANs)
* Open ports and network services
